VeriTrack Solutions: A Web-App Municipal Assessor Information System with Property Verification and Online Certification Requests for the Municipality of Rizal, Palawan

Design a modern government enterprise-style web application with a professional LGU interface using blue, white, gray, and minimal accent colors. The design must look realistic, responsive, and suitable for actual deployment in a Municipal Assessor’s Office.

The system should contain:

Responsive sidebar navigation
Top navigation bar
Analytics dashboard
Advanced tables
Search and filter system
File upload areas
QR verification
Charts and statistics
Printable forms
Approval workflow
Notifications
Audit trail system

The system must support 4 roles:

Admin
Provincial Assessor
Staff
Property Owner/User

NO PUBLIC REGISTRATION.
Accounts are created ONLY by the Admin.

Users can only access property records assigned to their account for confidentiality and security purposes.
